📦 What This Package Is

coco9-storefront-ui is a ready-made collection of six digital storefront themes. Think of a "theme" as a complete look for an online shop page: the layout, the colours, the product boxes, the buttons and the wording. You do not need to design anything from scratch, and you do not need to write code.

Everything in this package is built with three ordinary web languages that every browser already understands: HTML for the structure, CSS for the appearance, and JavaScript for the small interactive touches such as opening a menu or switching product images. Because of that, there is nothing to compile, nothing to install and no special software environment to set up. You download the files, you open one of them in your browser, and the storefront appears.

The package also includes a standalone demo. The demo is a single starting point that lets you click through the six themes and compare them side by side before you decide which one to use. It runs entirely inside your browser using the files you downloaded, so it works even without an internet connection.

💻 Before You Start

You need a Windows computer and a modern browser such as Microsoft Edge, Google Chrome or Mozilla Firefox. Any recent version will do. Windows 10 and Windows 11 are both fine.

You do not need to install a programming editor, a server, or any extra runtime. A simple text editor is enough if you later want to change a colour or a word. On Windows, the built-in Notepad application is sufficient for that job.

You will also need about 15 megabytes of free disk space and a folder where you are allowed to save files, such as your Documents folder or your Desktop. Nothing in this package writes to the Windows registry, starts automatically with your computer, or runs in the background.

Finally, note that these are front-end themes. They show storefront designs and interactive page behaviour. They do not process payments, store customer data or connect to a shop database. They are the visual layer you build on top of, or simply preview.

When the page opens, use the green download control to save the package to your computer. Windows will place it in your Downloads folder unless you choose a different location. If your browser asks whether to open or save the file, choose save so you keep the original copy.

Once the download finishes, unzip the package if your copy arrives as a compressed folder: right-click the file and choose Extract All, then confirm the destination. Keep all the folders together in one place. The themes depend on their neighbouring image and style folders, so moving a single file out on its own can break the appearance.

🖱️ Opening Your First Theme

  1. Open the folder you extracted the package into.
  2. Look for the demo page file, which ends in .html. It is the entry point for the whole collection.
  3. Double-click it. Windows will open it in your default browser, and the demo gallery will appear.
  4. Click through the six themes to preview each one at full size.
  5. To view a theme on a phone-sized screen, drag the edge of your browser window inward. The layout will rearrange itself as the window narrows.
  6. To open a specific theme directly instead of the gallery, double-click any of the other HTML files in the theme folders.

🎨 Changing Colours, Text and Pictures

Every theme folder contains its own style file and its own page file. To change a headline, open the page file in Notepad, find the sentence you want to replace, type your own wording in its place, then save the file. To change a colour, open the style file and look for the colour values, which appear as codes beginning with a hash symbol. Replace a code with another one and save.

To swap a picture, drop your own image into the theme's image folder using the same file name as the original, and the theme will display yours instead. Keep the file names identical and the rest of the layout stays untouched.

After any change, save the file and refresh the page in your browser. If something looks wrong, press the refresh button while holding the Shift key to force the browser to reload the style file.

❓ Common Questions

Do I need to install anything? No. Open the HTML file in your browser and the themes run. There is no setup wizard and no background process.

The page opens as plain text instead of a design. Right-click the HTML file, choose Open With, and pick your browser from the list. Once chosen, Windows remembers it.

Pictures are missing after I moved files. Return the moved files to their original folders so every theme keeps its images and styles beside it.

Can I use these on a real shop? Yes. The MIT licence allows commercial use. You will still need your own hosting and your own checkout system, since these files are the design layer only.

Can I put my shop name and logo in? Yes. Edit the text directly in the page file and replace the logo image with a file of the same name.
